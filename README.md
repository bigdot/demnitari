# demnitari.ro

Afla cine te reprezinta in parlament.

Din 2016 parlamentarii se aleg pe liste la nivel de judet, pentru ambele camere.

Localitatea serveste la aflarea circumscriptiei.

## Surse de date

- [cdep.ro](https://www.cdep.ro) — Camera Deputaților și Senatul (liste, profiluri, CV-uri).
- [senat.ro](https://www.senat.ro) — biografiile senatorilor (contact în teritoriu).
- [data.gov.ro](https://data.gov.ro) — nomenclatorul SIRUTA (localități).

Date publice, republicate ca atare. Dacă găsești o eroare într-un profil, sursa e unul din
site-urile de mai sus.
